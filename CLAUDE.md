# WebsiteToLife — Claude Code project instructions

This repo builds and maintains websites and AI operating workflows for small local businesses.

- For any client automation work, use the `service-business-ops-builder` skill.
- Folder per client: `clients/<client-slug>/` containing discovery.md, stack.md, rules/, build/, compliance.md, handoff.md.
- Workflow: read relevant files → propose a short plan → wait for Marshall's approval → execute.
- Never put API keys or passwords in files or commits.
- Anything a client reads: plain English, short, no jargon.
- Never send real messages, charge cards, or place orders during development — use test/sandbox accounts.
