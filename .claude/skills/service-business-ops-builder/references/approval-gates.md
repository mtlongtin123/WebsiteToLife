# Approval gates

| Action | Default | Can graduate to AUTO? |
|---|---|---|
| Replying to a new lead / asking questions | AUTO (after shadow) | yes |
| Booking a free estimate/consult | AUTO | yes |
| Sending a price or quote | APPROVE | only fixed-price listed services |
| Discounts, negotiation, contract terms | HUMAN-ONLY | never |
| Ordering materials / spending money | APPROVE | never above owner's set limit |
| Contacting a backup subcontractor | APPROVE | owner's choice |
| Telling a client about a delay/problem | APPROVE | yes, with templates |
| Sending an invoice matching an accepted quote | APPROVE | yes |
| Payment reminders (friendly) | AUTO after template sign-off | yes |
| Late fees, collections, liens, legal threats | HUMAN-ONLY | never |
| Changing prices or rules files | HUMAN-ONLY | never |
| Refunds | HUMAN-ONLY | never |

Graduation rule: a message type moves to AUTO only after the owner approves
~20 consecutive drafts without edits, and Marshall confirms.
